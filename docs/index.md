# Rust 教學

從第一個可執行的程式開始，逐步認識 Rust 的語法、所有權與借用。

## 學習路線

1. [準備開發環境](getting-started/installation.md)：安裝 Rust 工具鏈並認識 Cargo。
2. [第一個 Rust 程式](getting-started/hello-world.md)：執行範例，理解 main 與 println!。
3. [變數與型別](fundamentals/variables.md)：認識 let、型別推導與不可變性。
4. [所有權與借用](ownership/index.md)：建立理解值的生命週期與存取方式的基礎。

## 如何使用這份教材

先閱讀章節，再執行對應的範例。修改程式時觀察編譯器訊息，並用章節最後的練習確認自己的理解。

本站的可執行程式碼直接引用儲存庫中的 Rust 範例，方便你閱讀、修改與執行同一份程式。
