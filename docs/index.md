# Rust 教學

這份教學以正體中文解說 Rust，面向具備基本 Python 經驗的讀者。

目前可閱讀第 1–5 章：從環境安裝與 Cargo 開始，寫出數值計算、拆分 module，再學 struct、ownership、reference、enum、泛型、文字與 Vec，接著用 trait、HashMap、lifetime annotation、格式化與轉換建立清楚的資料介面。後續章節會加入 closure 與 Iterator，再進入並行、async、unsafe 與實戰專案。

教學範例會依序使用已經介紹的概念，讓你能邊讀、邊理解、邊動手寫。
