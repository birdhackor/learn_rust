# 變數與型別

## 學習目標

- 用 let 宣告變數。
- 理解 Rust 會根據值推導型別。
- 認識不可變變數與 mut 的差別。

## 從範例觀察

```rust title="main.rs" linenums="1"
--8<-- "examples/hello-world/src/main.rs"
```

language 的初始值是字串字面值 "Rust"，編譯器會推導其型別為 &str，也就是字串切片的參考。

let 宣告的變數預設不可變，因此建立後不能直接指定另一個值。需要重新指定值時，在變數名稱前加上 mut。

不可變性可以幫助讀者理解程式：沒有 mut 的變數不會在後續被重新指定。

## 練習

在 let 宣告之後加入 language = "Ferris";，觀察編譯器如何說明不可變變數的問題。

依照編譯器建議加入 mut，重新執行。練習完成後還原範例，確保教材的測試仍可通過。
