# 1.4 保存數值，決定型別與運算

接下來要算一筆訂單：單價 120 元、數量 3，商品總額應是 360。先替材料命名，再讓程式算出答案。以下指令與後續本章指令都在教材 repo 根目錄執行，使用上一節的 `intro-steps` package。

## 名稱讓材料與結果對得起來

`let price: i32 = 120;` 宣告一個叫 `price` 的**變數**，讓這個名稱對應到值 `120`；這個名稱與值的關聯也叫 binding。`=` 在這裡指定初始值，不是數學上的等號比較。名稱通常用小寫，多字以底線相連，例如 `item_total`。

冒號後的 `i32` 是**型別**，決定這個值可表示什麼、可以做哪些運算。`i32` 能保存有正負號的整數，範圍是 −2,147,483,648 到 2,147,483,647；本例的價錢與數量都在範圍內。`120`、`3` 則是直接寫出的整數 literal。

乘法用 `*`。顯示結果時，`println!` 中的 `{total}` 是格式字串的佔位，會顯示這個名稱目前的值；雙引號內的其他文字照原樣顯示。先看完整程式中的這一段：

```rust
--8<-- "examples/intro-workspace/steps/examples/types.rs:price"
```

`price * count` 先讀兩個值再相乘，結果成為 `total` 的初始值。`total` 沒寫型別，編譯器仍能由兩個 `i32` 的乘法**推導**出它是 `i32`。Rust 在編譯時就要確認型別；省略標註並不等於執行時可以任意換型別。

## 除法先問：想得到整數還是小數

Rust 的 `+`、`-`、`*` 分別做加、減、乘；`/` 做除法，`%` 取餘數。這裡沿用你已熟悉的數字，觀察 `7` 分成每份 `2` 的結果。若要小數結果，`f64` 是能表示小數的浮點數型別，材料改寫成 `7.0`、`2.0`：

```rust
--8<-- "examples/intro-workspace/steps/examples/types.rs:division"
```

兩個整數相除仍得到整數，`7 / 2` 是 `3`，`7 % 2` 是 `1`。整數除法朝零截去小數部分，因此 `-7 / 2` 是 `-3`。這與 Python 的 `/` 不同；Rust 不會自動把這次整數運算改成浮點數。

將材料寫成 `7.0`、`2.0`，這次才得到 `3.5`。浮點數的表示空間有限，許多十進位小數只能近似表示；本例特別選了能清楚觀察的結果。運算通常需要兩邊是同一數值型別，不能直接把 `i32` 與 `f64` 混加。

乘除餘數的優先順序高於加減；若希望先相加，用括號明寫，例如 `(120 + 20) * 3` 是 `420`，`120 + 20 * 3` 是 `180`。不要以換行或空白代替括號。

## 其他單一值的型別

有些材料只需要非負整數。`u8` 的範圍是 0 到 255，`u32` 的範圍是 0 到 4,294,967,295；`u` 表示不帶正負號，`i` 表示可帶正負號。名稱中的數字是表示空間的 bit 數，第 1.7 節會把 bit 和記憶體連起來。選較小型別不會讓超出的值自動擴大：例如 `u8` 不能保存 `256`。

`bool` 只有 `true` 與 `false` 兩個值，適合保存「是否備妥」；`char` 保存一個 Unicode 純量值，用單引號，例如 `'甲'`。Unicode 是表示文字的通用編號系統；一個 `char` 不一定等於螢幕上一個完整符號，文字細節後面再談。雙引號的 `"甲"` 是字串 literal，與這個單引號值的型別不同。

數字中也可以加底線方便閱讀：`1_000` 的值仍是 1000。

```rust
--8<-- "examples/intro-workspace/steps/examples/types.rs:scalars"
```

這些值都能直接透過 `{名稱}` 顯示。一般沒有其他線索時，整數預設為 `i32`、浮點數預設為 `f64`；明寫型別則讓讀者和編譯器都知道這裡的選擇。

數值運算也必須落在型別可表示的範圍內。超出範圍稱為**溢位**；本章先用確定落在範圍內的材料，不依賴溢位後的結果。先把 `i32`、`f64`、`bool`、`char` 用清楚，比背完所有數值型別更有幫助。
