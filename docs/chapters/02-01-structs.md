# 2.1 用 struct 為資料的角色命名

上一章把一筆訂單寫成 `(120, 3)`：第一項是單價，第二項是數量。計算本身沒有問題，但看到 `order.0` 時，仍要記得第零項代表什麼。這一節保留相同材料，讓「單價」與「數量」直接成為資料的一部分。

## 定義型別，再建立一筆資料

**struct** 是把相關欄位組在一起的自訂型別，也常稱為結構。**欄位**有自己的名稱與型別，因此不需要用位置猜角色。這裡將型別命名為 `Order`，放入 `unit_price: i32` 與 `count: i32` 兩個欄位。自訂型別的名稱通常用大寫開頭，例如 `Order`；欄位和變數一樣使用小寫及底線。

`struct Order { ... }` 定義資料的形狀；它本身還不是某筆單價 120 的訂單。要建立一個**實例**，也就是符合這個型別的一個具體值，寫 `Order { unit_price: 120, count: 3 }`。冒號左邊是欄位名，右邊是這一筆的值；各欄位以逗號分隔，最後一項也可以留下逗號。

`order.unit_price` 取出這筆資料的單價，`order.count` 取出數量。和 tuple 的 `order.0` 相比，點號後面現在是欄位名。這裡的資料仍是數字，乘法與 `println!` 都可以沿用上一章。

## 修改一個欄位，重新計算答案

要把數量加一，持有這筆訂單的變數要宣告成 `let mut order`。`order.count += 1;` 修改其中的數量欄位，單價保持 120。`mut` 放在變數宣告，而不是放在 struct 的欄位定義中。

下面先保存原小計，再修改數量並算新小計。注意第一個已算出的數字不會自動更新，和 1.4 的變數練習相同：

```rust
--8<-- "examples/ch02-ownership/src/main.rs"
```

從 repo 根目錄執行新 package：

```bash
cargo run -p ch02-ownership --locked
```

```text
原小計=360，加一件後=480
```

資料的表示換了，計算規則仍是單價乘數量。struct 的收益是讓相關值收在同一筆具體資料裡，並讓操作位置說出欄位的角色；tuple 仍適合簡短組合，並沒有失去原本能完成的工作。

本例把 `Order` 與 `main` 放在同一個 binary crate，沿用上一章已學的 package 選擇方式。先不嘗試直接顯示整個 `Order`；這裡已教的顯示操作針對它的數字欄位。

## 練習：改材料，保留同一種資料形狀

建立單價 80、數量 2 的 `Order`。保存原小計，把同一筆訂單的數量加一，再算新小計。用已學的數值 assertion 確認答案是 160 與 240，最後顯示兩個結果。

如果把兩個欄位在實例中的列出順序交換，只要仍寫對欄位名稱，資料角色就不會交換。這和 tuple 依位置對應的規則不同。

完成後可對照 [參考程式](https://github.com/birdhackor/learn_rust/blob/main/examples/ch02-ownership/examples/structs_solution.rs)，或執行 `cargo run -p ch02-ownership --example structs_solution --locked`。
