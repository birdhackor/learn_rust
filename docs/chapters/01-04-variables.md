# 1.4 用變數保存數字

固定文字已經能顯示，現在要算一筆訂單：單價 120、數量 3，總額應是 360。若只把 `360` 寫在字串裡，它不會隨單價或數量改變。我們需要保存材料，讓程式用材料計算答案。

## 名稱、值與型別

**變數**把一個名稱和一個值連在一起。`let price: i32 = 120;` 的意思是建立名為 `price` 的變數，型別為 `i32`，初始值是 `120`。`let` 宣告變數；`:` 後面是型別；`=` 右邊提供值；分號結束這項宣告。名稱通常使用小寫，數個單字以底線隔開，例如 `unit_price`。

**型別**決定這個值能表示哪些資料，以及哪些操作有效。Rust 在編譯時就要知道型別，和 Python 執行時同一名稱可以隨時指向不同型別的值有所不同。數字直接寫在程式裡，例如 `120`，稱為數字 literal；可在數字中放底線幫助閱讀，`1_000` 和 `1000` 是同一個值。

本節需要的基本型別如下：

| 型別 | 能表示的資料與現在的用途 |
| --- | --- |
| `i32` | 可正可負的整數，使用 32 bits。bit 是能表示 0 或 1 的單位；固定數量的 bits 意味著數值範圍有限。`i32` 範圍是 −2,147,483,648 到 2,147,483,647，足以放本章的小數字。 |
| `u32` | 不能為負的 32-bit 整數，範圍 0 到 4,294,967,295。`i` 表示有正負號，`u` 表示無正負號。 |
| `usize` | 不能為負的整數，大小由執行程式的目標平台決定，常見 64-bit 平台上是 64 bits。後面用來表示資料長度與位置；它不等於固定的 `u32`。 |
| `f64` | 使用 64 bits 的浮點數，能表示小數與負數，例如 `3.5`、`-2.5`。浮點數的精度有限，並非所有十進位小數都能精確表示。 |
| `bool` | 布林值，只有 `true` 和 `false`，用來記錄是／否。這和 TOML 的是／否設定用途相似，但這裡是 Rust 程式中的資料。 |

其他整數大小也遵循相同命名：`i8`／`u8`、`i16`／`u16`、`i64`／`u64`、`i128`／`u128`，以及依平台大小而定的 `isize`。例如 `u8` 使用 8 bits，可表示 0 到 255。選型別時要考慮資料範圍，不能把 Rust 整數當成 Python 那樣能自動增長的整數。

若沒有寫 `: 型別`，編譯器可以根據值與後續用法做**型別推導**。沒有其他限制的整數通常採用 `i32`，浮點數通常採用 `f64`；若後續操作要求另一個型別，推導也可能採用那個型別。省略註記不表示變數沒有型別。

## 計算並顯示變數

`+`、`-`、`*` 分別做加、減、乘。要把結果放進顯示文字，在 `println!` 的格式字串裡寫 `{變數名稱}`；它會在該位置顯示變數的值。例如 `{total}` 顯示計算後的總額，而不是文字 total。這是 `println!` 的顯示語法，不是另一種建立變數的方法。

現在可以讀懂這個程式的每個材料與操作：

```rust
--8<-- "examples/ch01-basics/examples/variables.rs"
```

這份 repo 的 `ch01-basics` package 放了數個獨立的**範例目標**：`examples/variables.rs` 是一個 binary crate，它有自己的 `main`。`--example variables` 依檔名選擇這個範例目標，名稱不加 `.rs`。從 repo 根目錄執行：

```bash
cargo run -p ch01-basics --example variables --locked
```

預期輸出：

```text
單價=120，數量=3，總額=360
ready=true，position=0
```

把 `price` 改成 `80` 後，總額變成 240。因為程式重新計算 `price * count`，不是把舊的答案改成另一段固定文字。

### 整數除法與小數除法

`/` 做除法，但整數相除的結果仍是整數，小數部分往零截去；`7 / 2` 是 `3`，`-7 / 2` 是 `-3`。`%` 取餘數，`7 % 2` 是 `1`。浮點數相除可得到小數；要做這種計算，本例兩邊都寫成浮點數，不把 `i32` 和 `f64` 直接混在同一個運算中。

```rust
--8<-- "examples/ch01-basics/examples/arithmetic.rs"
```

```bash
cargo run -p ch01-basics --example arithmetic --locked
```

輸出是整數商 3、餘數 1、小數商 3.5、溫度 −2.5。整數除法與餘數運算的除數不能是零；整數運算也必須留在型別可表示的範圍內。現在採用的小數字不會碰到範圍上限。超出範圍稱為 overflow，預設開發建置的整數運算會在發生 overflow 時停止程式；不能靠改成另一種建置方式當作資料處理政策。

## immutable 與 mutable

Rust 變數預設是 **immutable**：初始值已給定後，不能再對同一個變數指派另一個值。這讓你可以從宣告看出哪些數字在後面會保持不變。下面是故意不能通過編譯的練習，因為第二次對 `count` 指派違反規則；它放在 `fixtures/compile-fail/`，不會混入正常範例目標：

```rust
--8<-- "examples/ch01-basics/fixtures/compile-fail/immutable.rs"
```

若把這段放進練習用的 `main.rs` 並執行 `cargo check`，會收到 `cannot assign twice to immutable variable`。重點是它在執行前就被拒絕，不是印出結果後才報錯。

確實需要修改同一個變數時，在名稱前加 `mut` 使它成為 **mutable**。`let mut count: i32 = 3;` 仍建立一個 `i32` 變數，只是允許後續重新指派；`count += 1;` 先讀舊值、加一，再保存新值。`+=` 把「對目前的值相加，再存回同一變數」合成一項操作：

```rust
--8<-- "examples/ch01-basics/examples/mutability.rs"
```

```bash
cargo run -p ch01-basics --example mutability --locked
```

你會先看到 3，再看到 4。`mut` 不會允許這個 `i32` 變數突然變成 `bool`；型別在編譯時已決定。

## shadowing 建立的是新變數

重寫 `let` 並使用相同名稱，會建立一個新變數，讓後續這個名稱指向新變數。這叫 **shadowing**。右邊的計算仍可使用先前的同名變數；宣告完成後才換成新的。

```rust
--8<-- "examples/ch01-basics/examples/shadowing.rs"
```

```bash
cargo run -p ch01-basics --example shadowing --locked
```

第一行輸出 380，第二行輸出 `true`。後面的 `total` 是一個新的 `bool` 變數，不是修改原來 `i32` 的型別。因此 shadowing 不需 `mut`。本例故意換成不同用途來看出型別差異；實際程式若已從總額換成是否完成，命名為 `ready` 通常更清楚。

## 練習：數量改了，哪些答案會跟著改

建立單價 80、初始數量 2 的變數。先算出原總額，再把同一個數量變數加一，算出新總額，最後一次顯示兩個答案。先預測輸出為 160 與 240，再執行驗證。

要留意：先前計算並保存的 `before` 不會因為 `count` 改變而自動重新計算。運算發生在執行那一行的時刻，變數保存的是當時得到的值。
