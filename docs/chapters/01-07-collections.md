# 1.7 一組資料：tuple、array 與 range

前面一筆訂單有單價與數量；若想把它當成一份資料，就需要一種能把這兩個值組在一起的表示。另一方面，一份價目表有數筆相同型別的價格，我們希望能按照位置取出其中一筆。這兩項需求分別適合 tuple 與 array。

## tuple 把不同角色的值放在一起

**tuple** 是固定數量的值組合，各位置可以有不同型別。`(120, 3)` 是兩項數值的 tuple，型別可寫成 `(i32, i32)`。位置從零開始：`order.0` 取第一項，`order.1` 取第二項。這裡兩個位置的角色不同，第一項代表單價、第二項代表數量，即使本例的型別恰好相同，也不能任意交換。

`let (price, count) = order;` 稱為**解構**：用相同形狀的一組名稱取出各位置的值，後面即可用清楚的名稱計算。若 tuple 有兩項，解構也要對應兩項。

本節的顯示也會用到 `println!("{}", 值)`：格式字串裡的空 `{}` 依序對應後面以逗號分隔的值。這讓我們可以直接顯示 `order.0` 這類操作結果，不必先為每個結果建立變數。帶名稱的 `{total}` 和空 `{}` 可以在同一行使用。

## array 保存相同型別的一列值

**array** 是固定長度、每項型別相同的一列資料。值寫成 `[120, 80, 200]`，型別寫成 `[i32; 3]`：分號前是元素型別，後面是元素數量。這個型別中的分號是分隔兩項設定，不是結束一項 statement。

`prices[position]` 依**索引**取出該位置的值。索引是從零開始的位置數字，型別為 `usize`；3 項 array 的有效索引是 0、1、2。

`prices.len()` 回傳長度，型別是 `usize`。這是以資料為起點呼叫操作的寫法：點號後是操作名稱，空 `()` 表示不再提供額外參數，`len` 讀取這個 array 的元素數量。這種操作稱為 method；本節只使用 array 上的這項具體操作，後面會學如何為自己的資料定義 method。

array 也能用 `let [first, second, third] = prices;` 解構，但名稱數量必須與固定長度一致。若要建立三個都為零的元素，寫 `[0; 3]`；它表示重複同一個數值三次，和列出三個不同值的逗號寫法不同。

現在程式依序組合一筆訂單、取出價目表中的第二筆，再建立三個零：

```rust
--8<-- "examples/ch01-basics/examples/collections.rs"
```

```bash
cargo run -p ch01-basics --example collections --locked
```

```text
單價=120，數量=3，總額=360
長度=3，索引1的值=80
三筆價格=120、80、200
重複建立的第一項=0
```

tuple 與 array 都把數個值組在一起，但當用途是「第零項是單價、第一項是數量」，tuple 的各位置有不同角色；當用途是「每項都是價格，可用位置選一筆」，array 的同型元素與長度更適合。它們都不會在這個程式中自動增加第四項。

## 索引必須留在邊界內

長度是項目數量，最大有效索引則是長度減一，所以長度 3 不代表可以取索引 3。當索引在執行時越界，程式會 **panic**：停止原來的正常流程並回報錯誤，不會給你一個隨意的數字。

以下是故意在執行時失敗的完整程式，存放在 `fixtures/runtime-fail/`，不作為正常 Cargo 範例執行。它接受一個索引，卻呼叫了 3；先預測失敗的位置，再放進自己的練習專案執行：

```rust
--8<-- "examples/ch01-basics/fixtures/runtime-fail/index_bounds.rs"
```

你會看到 `index out of bounds`，而不是 `println!` 的數字輸出。編譯器已看得出的某些越界寫法也會提前拒絕；這個函式範例用來觀察執行時的邊界檢查。後面教 `Option` 時，會學習如何以可處理的缺值結果代替直接索引。

## range 描述一串位置

下一節要依序處理多個數字。**range** 描述起點與終點之間的範圍，對本章的整數用途而言：

| 寫法 | 下一節逐項走訪時會取得的數字 |
| --- | --- |
| `0..3` | 0、1、2；包含起點，不包含終點 |
| `0..=3` | 0、1、2、3；包含兩端 |
| `2..2` | 沒有項目，因為起點已到不包含的終點 |

range 不是把這些數字先存成一個 array，而是用起點與終點描述走訪的範圍。它和 array 索引能配合：3 項資料的索引是 `0..3`，不是 `0..=3`。當然，直接走訪 array 的每項值通常更省事，不一定需要自己管理索引。

## 練習：對應角色與位置

用 tuple 保存單價 80、數量 3，解構後算小計；再用 array 保存 80、120、200，取得最後一項。先寫下最後一項的索引與型別，再執行。答案應是小計 240、索引 `2`、索引型別 `usize`、最後一項 200。
