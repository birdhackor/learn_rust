# 所有權與借用

## 學習目標

- 認識所有者、移動與借用的意思。
- 理解為什麼不同型別的指定行為需要分別觀察。

## 所有權

Rust 透過所有權規則管理值的生命週期。每個值都有所有者；所有者離開作用域時，該值會被清理。

將值指定給另一個變數，可能移動所有權，也可能複製值，取決於該型別是否實作 Copy。

String 擁有自己的字串資料，適合觀察所有權移動。第一個範例使用的 &str 則是字串切片的參考，不能直接用它的指定行為推論 String。

## 借用

借用讓程式透過參考存取值，而不必轉移所有權。共享參考可讀取資料；可變參考可用來修改資料。

一般而言，同一段資料在某個時間點可有多個共享參考，或一個可變參考。參考也必須保持有效，不能指向已被清理的值。

## 延伸閱讀

閱讀 [The Rust Programming Language：Understanding Ownership](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html)，並分別觀察 String 與參考的範例。
