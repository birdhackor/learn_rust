# 第 1 章作者來源閱讀紀錄

- 作者角色：第 1 章作者；這份文件不是獨立審閱或首次讀者紀錄。
- 閱讀日期：2026-10-14。
- 動筆前透過網路開啟以下相應章節；按本課實際順序重組教學，不照搬措辭或假設原教材的前置順序適合本課。

| 本課位置 | 實際閱讀來源與部分 | 借鑑方式／避開的先備問題 |
| --- | --- | --- |
| 1.1 | [Rust Book Installation](https://doc.rust-lang.org/book/ch01-01-installation.html)：command line notation、Linux/macOS／Windows、linker、版本驗證；[繁體 Book 安裝](https://rust-lang.tw/book-tw/ch01-01-installation.html) | 工具先分角色再驗證；解釋終端指令符號與 linker，不要求 Python 讀者先懂 C。繁體版本較舊，版本與 edition 以當前官方文件及專案實測為準。 |
| 1.2 | [Hello World](https://doc.rust-lang.org/book/ch01-02-hello-world.html)：main／macro／編譯執行；[Hello Cargo](https://doc.rust-lang.org/book/ch01-03-hello-cargo.html)：建立專案、TOML、check/build/run；[繁體 Hello Cargo](https://rust-lang.tw/book-tw/ch01-03-hello-cargo.html) | 第一個程式只印固定文字；在展示前說明最小語法。把不同 Cargo 命令對應到是否產生／執行程式，讓修改後輸出可驗證。 |
| 1.3／1.9 | [Packages and Crates](https://doc.rust-lang.org/book/ch07-01-packages-and-crates.html)、[Defining Modules](https://doc.rust-lang.org/book/ch07-02-defining-modules-to-control-scope-and-privacy.html)、[Paths](https://doc.rust-lang.org/book/ch07-03-paths-for-referring-to-an-item-in-the-module-tree.html)、[use](https://doc.rust-lang.org/book/ch07-04-bringing-paths-into-scope-with-the-use-keyword.html)、[拆檔](https://doc.rust-lang.org/book/ch07-05-separating-modules-into-different-files.html)；[繁體 package/crate](https://rust-lang.tw/book-tw/ch07-01-packages-and-crates.html)、[繁體拆檔](https://rust-lang.tw/book-tw/ch07-05-separating-modules-into-different-files.html) | package／crate 早教以解釋第一次跑教材；module 等函式已教後再教。以同一計價函式拆成 library，讓分工收益與修改前後結果直接對應，避免餐廳案例突然增加陌生函式群。 |
| 1.3 | [Cargo Book Workspaces](https://doc.rust-lang.org/cargo/reference/workspaces.html)：members、shared lockfile、workspace.package；[Manifest](https://doc.rust-lang.org/cargo/reference/manifest.html)：package 名稱／edition／rust-version／publish | 逐欄解釋眼前的設定、工作目錄、選 package 與 --locked；resolver 只教目前的版本選擇角色，不帶入尚未使用的 dependency graph。 |
| 1.4 | [Variables and Mutability](https://doc.rust-lang.org/book/ch03-01-variables-and-mutability.html)、[Data Types](https://doc.rust-lang.org/book/ch03-02-data-types.html)；[繁體變數](https://rust-lang.tw/book-tw/ch03-01-variables-and-mutability.html)、[繁體型別](https://rust-lang.tw/book-tw/ch03-02-data-types.html) | 借鑑不可重新指派→mut 的有意義錯誤；不用原文 String／len 的 shadowing 案例，改成數值到 bool，避免 reference／文字 API 提前出現。型別推導不用 parse/expect/FromStr。 |
| 1.5 | [Functions](https://doc.rust-lang.org/book/ch03-03-how-functions-work.html)；[繁體函式](https://rust-lang.tw/book-tw/ch03-03-how-functions-work.html) | 用同一數值運算展示輸入與輸出；尾端 expression 與分號差異要先說清楚，再給預期失敗例。先教 ()，不把函式無回傳結果當作沒有型別。 |
| 1.6–1.8 | [Control Flow](https://doc.rust-lang.org/book/ch03-05-control-flow.html)；[繁體控制流程](https://rust-lang.tw/book-tw/ch03-05-control-flow.html)；Data Types 的 tuple／array | 沿用計價任務，tuple／array/range 先於 for；array 直接逐項數值迭代只教本次具體契約，不提前塞 Iterator trait 或借用。變動索引才展示執行期邊界失敗。 |
| 1.10 | [How to Write Tests](https://doc.rust-lang.org/book/ch11-01-writing-tests.html)：test attribute、assert/assert_eq、unit test；[繁體測試](https://rust-lang.tw/book-tw/ch11-01-writing-tests.html)：相應部分 | 把測試接回已完成的數值 library。先解釋屬性、cfg 與 assertion，再展示。避免 derive、Result-returning tests、String、std::process 與泛型helper。 |

以上來源的長篇內容不是本課必要外部先備。讀者只讀本章正文即可完成本章操作；外部連結提供對照與進一步查證。
