## 預定 SVG 圖意（尚未繪製／驗證）

1. **2.2：同一資料的 move 與數值 Copy。** 左半畫 `first: Dimensions` 移交到 `second`，原名稱劃除，新名稱保留可用；右半畫 `a: i32` 指派到 `b` 形成兩個獨立值。箭頭表示「語意上轉交」，不表示實際搬動 heap bytes。先用正文定義圖中每個名稱。
2. **2.2：函式 stack frame 與 heap 的概念分工。** 垂直排列呼叫 frame，另外畫經位置資訊連到獨立配置的 heap 資料。圖不含 `Box`／`String` 程式，也不宣稱第 2 章範例發生 heap allocation；heap 在這裡只建立日後需要的角色。
3. **2.3：owner 與 reference。** `shape` 的同一數值框保留 owner 標記；`r: &Dimensions` 的箭頭標「借用」，不得與 move 的箭頭混用；再用小圖把 `r` 與 `*r` 對應不同對象。
4. **2.4：borrow 區間。** 沿已展示程式的行號畫 shared borrow 的首次建立與最後使用，再畫其後合法修改。加第二次使用後區間延伸的對照，讓讀者看見衝突何時產生；名稱 scope 另畫到右大括號，不與 borrow 區間同長。
5. **2.6：array 中的 slice。** 四／五個數值格，每格標原 array index；框住 `1..4` 的三格，slice 相對 index 標 0、1、2，旁標長度 3；範例選取與圖中數值一致，不靠顏色辨識。
