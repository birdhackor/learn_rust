## 正式 API 查核

- [String::as_str](https://doc.rust-lang.org/std/string/struct.String.html#method.as_str)：借用涵蓋整段 String 的 `&str`，不是建立新字串。
- [String::push_str](https://doc.rust-lang.org/std/string/struct.String.html#method.push_str)：追加借來的 `&str` 內容；接收 `&mut self`，不能把「借用輸入」誤寫成完全沒有資料複製。
- [str::get](https://doc.rust-lang.org/std/primitive.str.html#method.get)：回傳 subslice 的 non-panicking 取得法；range 超出範圍或不在 UTF-8 分界時是 None。正式泛型簽名有 SliceIndex 與 associated type，本章教目前 range 使用的具體契約，不展示未教簽名。
- [Vec::as_slice](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.as_slice)：借用含整份清單的 `&[T]`。本章從此視圖進行 get／索引；正式文件的 I/O/unwrap 範例不適合本章。

## 待前文實際交付後採用的安排

1. 3.1 以一個 numeric enum 的互斥形態一路教 match、pattern 取資料、借用 pattern、if let、let else。先講 pattern 實際取得的值或 reference，再用它推理。
2. 3.2 先以同一個具體數字任務，使用型別能由已知分支推導的 Some/None、Ok/Err；自訂錯誤 enum 保留失敗資訊。此節不展示角括號的完整型別或泛型定義，3.3 先建立泛型再回頭寫出 `Option<i32>`／`Result<i32, ConcreteError>`。
3. 3.3 用泛型資料盒與不要求額外操作的函式建立 T 的契約，說明型別推導、明確型別與必要的 turbofish；不對任意 T 做數值運算或輸出。
4. 3.4 僅以 String::new、push_str、as_str 建立文字，再展示 move 與 borrowing；所有 `&str` 定義在第一個借用文字範例前。
5. 3.5 以 `A中🦀` 的 1／3／4 byte 分界圖和安全 get 建立 byte range 規則；圖中的邊界是範例 UTF-8 編碼，不表示每個中文或每個顯示字元的通用長度。len 顯式呼叫在 as_str 取得的視圖上。
6. 3.6 Vec 的 new/vec!/push/pop/len/as_slice/as_mut_slice 若使用，均在第一段使用前教契約；安全存取採 `values.as_slice().get(index)`。成果為保留原順序的非負數清單，靠已教 while/for 數字 range、if、索引和 push 完成，不用 closure、Iterator、sort、retain、Debug、derive、unwrap 或 `?`。
