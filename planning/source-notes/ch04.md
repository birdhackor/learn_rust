| `Copy` | [std Copy](https://doc.rust-lang.org/std/marker/trait.Copy.html)：move／copy、derive、允許條件 | Copy 是隱含 bitwise 複製語意，必須也有 Clone；自訂數值 struct 不自動 Copy。String／Vec 的 heap ownership 不可只複製持有資訊，所以不能 derive Copy |
| `Eq` | [std Eq](https://doc.rust-lang.org/std/cmp/trait.Eq.html)：比較契約與 derive | 以已教 PartialEq 為基礎，增加每個值都與自己相等的要求；Eq 沒有新方法。選用整數／String 鍵，避免把浮點 NaN 示例引成額外先備 |

| `Borrow` | [std Borrow](https://doc.rust-lang.org/std/borrow/trait.Borrow.html)：owned／borrowed 表示、Eq／Hash 一致要求與 HashMap 查詢用途 | String 可作 str 的借用表示，查詢不必建立 owned String。Borrow 不只是任意取得某個 reference；作鍵的 borrowed 表示需保持 Eq／Hash 行為。4.3 先教具體 String／str 情況，不貼含 `?Sized` 的泛型定義 |

## 本章預定寫法與等待條件

這是等待前文交付前的教學選型，不能當作前置已驗收證據。

- 4.1：兩個具有不同欄位的數值資料型別，要供同一小流程取得量測值；自訂單一方法 trait，再定義泛型 bound，最後用已教的測試驗證不同實作。`where`／多個 bounds 僅在實際有需求時引入。
- 4.2：同一小資料模型逐項增加 `Debug`、`PartialEq`、`Clone`／`Copy` 能力。每個 attribute 之前先說清會啟用的操作、生成的欄位行為與限制；測試與正文採相同順序。
- 4.3：從既有文字清單統計到 `HashMap<String, usize>`。先按已知字詞查結果，避免 HashMap 迭代、排序與固定 Debug 順序的隱藏先備。可用 `get_mut` 搭配 `match` 更新既有項目，缺鍵時才 insert；先完整交代兩個呼叫契約。
- 4.4：單一來源省略 → 多來源回傳需要簽名契約 → 不同資料存活範圍 → 僅一來源的較精確契約 → owned 回傳。必要的 outlives 有明確任務才補；annotation 絕不負責延長值的存活。
- 4.5：先只有一個 borrowed 欄位，後增一個獨立 borrowed 欄位，讓兩個 lifetime 的用途可見；用 method 比較省略輸出與明確欄位來源。待前文核對後決定實際 API、編譯失敗用例與 SVG。
- 圖解候選：4.1 共同行為與不同實作對同一流程的連線；4.3 query／map／回傳 reference 的三個不同身分；4.4 兩個來源與輸出可用區段；4.5 struct reference 欄位對來源資料的箭頭。必要圖貼正文原位置，並由整合者實際檢查桌面／手機版面。
- 尚待取得：第 1–3 章實際已教文字／程式版本、完整 API 位置與編譯失敗驗收機制。未取得前不寫本章正文、helper、測試、練習或答案。

2026-10-14，原作者再次實讀繁中 Book HashMap 的讀取／ownership／更新段，以及 std Eq 的完整相等規則、Borrow 的 String／str 查詢理由、HashMap 的 get／get_mut／insert API。

- 本例維持名稱與次數的共同任務，先示新增／替換／缺鍵，再做既有值累加；get 的 Option 用 match 明示，沒有照搬 Book 的 copied／unwrap_or 或 entry。
- Eq 在 PartialEq 既有一致性規則之外加上自反要求；Hash 與 Eq 配合才可按鍵查找，collision 仍需相等比較確認。實作 Hash 的 Hasher 簽名不帶入本節。
- Borrow 以 String／str 為具體起點，保留 owned／borrowed 表示的 Eq／Hash 一致性。大小寫判定不同的假設例用來說明這份身分契約，不提前寫 case-insensitive wrapper、AsRef 或 conversion trait。
- 兩個來源要分清：查詢用 &str 借自 query，成功回傳 &usize 借自 map。正常 example 在使用 found 前修改 query，負例則在使用 found 前修改 map，讓契約差別可觀察。
