獨立首讀曾在原稿當下把第一份交接視為下一單位才解說，該原紀錄保留；未因讀完後已能懂就讓首次使用時序放行。修後局部讀者及技術複查另記。此處只改正文，沒有為文句重跑完整 package。

Root 另從實際生成 HTML 查到 3.6 三處未加 code 標記的型別參數被當成 HTML tag，畫面漏掉 `Option<T>`／`Vec<String>`／`Vec<i32>` 的參數。已將原詞加 inline code，沒有改型別、API 或範例。這是 root 的呈現查漏，另記來源與時點，不算同行的獨立發現。修後 v5 收錄此修正，DOM 與畫面檢查另保存。
