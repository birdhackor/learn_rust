## if/else只走被選block，條件必為bool：已解釋

引用：「true…第一個block」「false…else」「不會都做一次」「expected bool, found i32」。

1. 作用／關係：把2.1的bool答案變成執行路徑；block是第1章已有的工作範圍。
2a. 機制：先判條件，只執行一側。i32的3本身不是bool，Rust不採Python非零即真。2b. 用途：只收一種運費，不能把兩側工作全部做完；也必須真正寫出要比較的關係。
3. 用法／輸出：用item_total>=300作條件；錯誤範例的if count應改成count>0來表達數量為正。失敗程式不會先顯示「有商品」。
4. 例子／限制：失敗原因是條件型別；沒有完整診斷排版。該例省略else，我依其只指定型別錯誤推論單邊工作可不寫else，但false時略過的細節在這裡未直接明述，保留為合理推論。

## if expression交出相容的分支值：已解釋

引用：「if也是expression」「0或20，成為運費」「不能一邊…i32，另一邊…unit」。

1. 關係：沿用第1章block尾端值初始化binding，但現在先選哪個block的值。
2a. 性質：兩個可能交出答案的分支要給相容數值型別；分支0/20無分號，外面的分號才結束let。2b. 用途：後面的總額計算需要一個明確型別的shipping，不能在其中一條路只做顯示而沒有數字。
3. 用法／輸出：`let shipping = if item_total >= 300 { 0 } else { 20 };`，160選20，300選0；初始化本身不印字。
4. 例子／限制：未示範完整型別相容表或隱式轉換；不以「相容」推論i32與f64可隨意混合。分支仍非新函式／frame。
