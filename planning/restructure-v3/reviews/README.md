# 本輪審閱證據

technical-early 保存獨立技術初判及提示後窄複核；continuity-early／continuity-late 保存獨立銜接與實頁初判。first-reader-ch01 是同一位AI讀者依釋放順序保存的閱讀紀錄；指定大改章逐段讀，其他前文作實際先備整頁讀。作者紀錄在上層author／sources文件，不能代替獨立審閱。

三組 crossref-final-* 合併覆蓋131頁的重排引用。原初判、修前hash、修後窄核及審閱者更正分開保留；不把修後結果覆寫成最初沒有問題。

此處保存報告、逐項來源與指紋等可供版本追溯的資料。實際執行完整log、瀏覽器原圖、第三方網頁下載快取與臨時審閱工具保留在工作區，不把外部教材全文重發到本repo。報告內的work絕對路徑是當時的執行環境證據位置；網路來源保留原網址、實讀range及hash。原artifact-hashes清單描述原工作區封存，不表示每個快取檔都發布於本目錄。

AI角色靜態閱讀、AI逐段試讀、程式實際執行與瀏覽器實看分開判斷；不宣稱真人學習實驗、未看答案的測驗或審閱者未實際做的執行。readiness檔案只固定root裁定後的目前版來源與教學位置，結構檢查不證明理解。
